# Chess with Rule Validation

SE307 – Programming with Python term project.

A two-player chess game built with Python and Pygame. The program validates
every move according to the official rules of chess.

## Features (planned)

- Graphical 8x8 board with Pygame
- Legal move validation for all pieces
- Check, checkmate and stalemate detection
- Special moves: castling, en passant, pawn promotion

## Setup

```powershell
git clone https://github.com/laldrell/chess-or-checkers-with-rule-validation.git
cd chess-or-checkers-with-rule-validation
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Run

```powershell
python main.py
```
